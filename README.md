# LCS2 Assignment - Coding Round for Mental Health Analysis

- The repository contains a solution to the assignment that was given as part of the coding round for lcs2 research position.
- main.ipynb contains the exported notebook from kaggle.
- MananChawla_LCS2_Round2_Report.pdf contains the final report for the project.
- AI_USAGE.md contains the responsible disclosure for AI tools used as required by the assignment.

## Reproducibility

- The code was written in a deterministic manner. 
- https://www.kaggle.com/code/mananapeejay/lcsassign is open for viewing and can be fully run end to end as a fresh notebook, a copy of which is in this repository.
- For running the notebook create a copy, add a kaggle secret named `HF_TOKEN` with huggingface authentication token which is required for restricted access to llama repository and run all the cells.
- All the json files and figures saved during the assignment are stored as kaggle outputs for the same notebook.
